# S54：先建立軍勢與巨型威脅

2026-09-13；研究，未改 runtime。已閱讀官網機型／第21話梗概，檢視本地官方 Morpho、Dinosauria 設定圖及 S53 實機近景；未觀看影片或閱讀小說全文。網頁均實際開啟，單張設定圖不當同比例尺。

## 結論

首選 **XM2 對 Ameise 群、後方一台 Morpho，鐵道旁開闊戰場**。第21話官方梗概證實突破軍團阻截後與 Morpho 對峙；敵機頁證實 Morpho 與其他軍團編隊。將阻截與對峙壓入同一鏡頭是遊戲改編，非宣稱逐格重現。鐵道是機型設定依據，具體地形與數量是構圖提案。[1][2][4]

## 尺度邊界

|機型|官方長／高|判斷|
|---|---|---|
|M1A4|5.4／2.1 m|高度不含砲架武裝。[3]|
|XM2|6.3／2.7 m|不含格鬥副臂裝備。[2]|
|Ameise、Löwe|未列|不能捏造長高；Löwe「兩倍以上」指主砲尺寸，不能推成整機倍率。[1]|
|Dinosauria|未列|官方只證實大型、逾100 t；不足以定成十倍高怪獸。[1]|
|Morpho|40.2／11.4 m|長約XM2的6.38倍、高約4.22倍；高度量測條件不同，不能直接當網格倍率。[1]|

Morpho 是橫向延伸的巨砲平台；保持長高和輪廓，不能豎起或等比例放大成高樓怪獸。後景透視會縮小它，應調鏡位、朝向與距離；不能為塞滿畫面偷偷加倍。

## 第一鏡提案（非原作數字）

- 前景：1台XM2置左下，右側留射線；斜後方低角度，完整四足可讀。可加1台側翼友機，避免密集遮擋。
- 中景：18–30台Ameise分三股由兩翼匯入，近段6–10台有清楚輪廓，其餘形成有間隙的軍勢；數量須另做效能驗證，不先全部套最高細節。
- 後景：1台Morpho斜側面沿鐵道展開，占畫寬約三分之一；用同地面的敵群、軌道、揚塵建立尺度，煙不能遮掉主要砲體。距離與鏡位先灰盒驗證。

## 最大落差順序

S53近景只有單機、平地、牆面，尚未呈現交戰事件。先做「我方—軍勢—巨砲」同框 → 正確剪影與透視尺度 → 三股逼近及主角射擊／後座／落足 → 分層煙塵、砲火與受光 → 才處理局部材質。

沿用現有渲染與已驗Ameise；依既有survey，M1A4可作明標的構圖替身，不能改名XM2。XM2及Morpho尚無本輪實檔驗收；先核現成素材，失敗再決定製作，勿拿放大Ameise充Boss。

## S56 獨立全場美術 QA

實際檢視：[環境空景](probe-assets/s56-environment-only.png)、[交戰構圖](probe-assets/s56-encounter-cinematic.png)、[斜俯檢查](probe-assets/s56-encounter-oblique.png)。本輪只看這三張靜態圖，未重新搜尋或驗動畫。

**結論：環境結構明確改善，整體美術不通過。** 建築已有側牆、屋頂及連續月台；固定鏡頭不再直接露出平面終止邊界，後方山體提供遮擋。可辨識鐵道工業區與兩側接敵空間，已超過S55的孤立牆片。但三圖不能證明鏡頭外的地形完整性，也不能把這項改善稱作《86》交戰場景完成。

主要問題限三項：

1. **環境仍是完好工業模型展示。** 建築／屋頂過於整齊完整、山體形成近似同高的密集土丘圍圈，地面為大面積重複表面；缺少能改變輪廓與通行關係的戰損。中央軌道視覺上直抵後方整面建築，沒有清楚的出入口／終點設施，戰場地理尚不可信。問題不在磚紋解析度。
2. **畫面沒有可辨識的交戰事件。** 主角與兩翼敵群關係可讀，但目前三圖未見砲口火光、彈著、碎屑、移動揚塵或受擊結果；敵群像停放於通道兩側。這是交火／地面互動特效與動作證據缺口，不能靠加建築或全畫面霧補足。
3. **Boss仍未形成視覺與設定都可信的核心。** Morpho砲身朝畫外右側，淡白機體與背後亮建築競爭；XM2較深且有密集表面細節，敵軍則大面積泛白，完成度不一致。已知Morpho按40.2 m長校正後高5.44 m，與官網11.4 m有待核對；本輪圖無法解釋差異，不可拉高或放大後宣稱比例修正。

**唯一最高優先：收集並歸檔一套有體積、帶戰損輪廓的鐵道／工業遺址場景資產。** 優先找同一套件中的破頂廠房、斷裂月台／路基、可堆放的結構瓦礫與合理的軌道出入口；必須有可檢視實檔，分開保存來源／授權、預覽與尺寸／格式記錄。挑選依據是能在現有全場鏡頭中建立破壞、掩體與深度，不是多幾種磚牆貼圖。取得合適套件前停止重複排牆與微調材質；交火資產及Morpho核對保留為後續明確缺口，不混稱已解決。
