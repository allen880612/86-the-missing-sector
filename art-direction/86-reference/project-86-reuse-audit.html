Project-86 素材重用稽核

查核日期：2026-09-12。範圍僅限 Taliayaya/Project-86 的公開 README、LICENSE、檔案樹、PR、release metadata 與小型文字檔；未 clone，只抓下文兩組最小 Git LFS 研究集，未下載遊戲、未安裝或開啟 Unity，也未稽核子模組內容。因此這是權利與庫存初篩，不是完整工程實測。

結論

這個 repo 證明已有相當完整的 86 機甲、動畫與 Unity 地圖工程可研究，但目前證據不足以把其中模型／地形視為可放心移植的「免費開源素材包」。 可以先研究其程式、結構與製作方法；根 GPL 可能涵蓋作者自行提供的素材，但第三方來源仍須釐清；不建議整包搬入正式版。S51 已對兩組來源較明確的機體完成本地實檔驗證，見素材盤點；不能把整庫未清楚的來源問題等同每個模型都無法研究。

此發現會提高「以 Unity 6.4 開一個唯讀相容性／資產盤點試驗」的價值，因 repo 本身是 Unity 6000.4.3f1 工程；它不足以支持現在遷移引擎。若最後不能合法重用資產，Unity 相容性優勢會大幅縮小。

Ameise 最小本地研究集（追加查核）

針對單一 Ameise 做較窄的查核後，結論可比上面的整庫保守判斷更積極：僅在本機研究、轉檔與改造，不公開散布的用途，有合理依據使用這組檔案。 根 GPLv3 未把 Assets/ 排除；README 又稱「all the game files」公開以便 coding、modeling contribution。GPL 明定可製作、執行與 propagation 而不 convey；私人修改本身不觸發提供 source 的散布義務。這不是對外發布的充分清權：86 原作造型屬衍生內容，repo 未出示原 IP 授權，提交者能否授予全部素材權利仍是待解問題。

歸屬證據也不是「無個別 license 所以不能用」：模型與兩張貼圖最初由 BricksA9 署名 commit 547aabde，經 PR #122 合入；模型 rig 又由同一作者在 commit 19ae17dd／PR #127 更新。PR 沒標第三方來源；repo 搜尋 asurada 只命中引用此模型的 prefab，未找到外部 attribution。這支持「貢獻者自製並放入 GPL repo」的合理推定，但不是權利保證。

判斷結論證據
免費遊戲是，可免費下載其 alpha build；但「免費玩」沒有授予抽取素材的權利。README：Download／Disclaimer 明稱 community fan game，且 Steam 仍需原 IP 授權。
開源程式根目錄標示 GPL-3.0，C# 原始碼公開；重用／散布 GPL covered code 須履行 GPL。LICENSE 是未加例外的 GPLv3 全文；repo 首頁 顯示 GPL-3.0。
可重用模型／地形未證實。 公開可見與位於 GPL repo，不等於每個素材的作者有權用 GPL 再授權；repo 沒有資產總表、逐項 license 或對 86 原作權利的授權。README 只列一般 contributions／fan-game disclaimer；模型 PR 只顯示提交者，沒有授權聲明。

  • Assets/PermResources/Animations/：Juggernaut dash／recoil／death、Grauwolf attack／dash／launcher／death、Reginleif recoil、Morpho forward／tail／wing／stunned、Ameise、Löwe、Dinosauria等 Unity animation/controller 資料。技術上多與 Unity GUID、骨架和 prefab 綁定，跨引擎不能假定即插即用。

LFS、子模組與第三方依賴

.gitattributes 將 *.fbx、*.unity、*.png、*.jpg、*.mp3、*.asset 等交由 Git LFS。檔案樹中這些 blob 常只有約 128–133 bytes，表示 Git 儲存的是 pointer；必須另取 LFS 物件才是內容；本次只下載上列兩組模型與貼圖，完整工程／TerrainData 未驗。

Assets/Additional Assets 是 gitlink；.gitmodules 指向 git@github.com:Project-86-Community/Project-86-Additional.git。主 repo 因此不是自足封包，而且使用 SSH URL；本次依限定未跨 repo 稽核。v2.0 亦在同批變更加入此子模組，6 km 地圖可能有部分依賴在其中，但目前不能斷言。

Packages/manifest.json 除 Unity URP、Terrain Tools、Animation Rigging、AI Navigation、VFX Graph、Netcode 等套件，還引用 Discord SDK、NuGetForUnity、UnityMeshSimplifier、HierarchyDecorator；Assets 內另有 FMOD、Steamworks.NET、BeamPackage、Gaia User Data、Day-Night Skyboxes、iPoly3D Server Room 等第三方內容。少數檔案有個別 license（FMOD、Steamworks、音樂、字型），但沒有一份涵蓋所有資產的 attribution/license manifest。Unity Asset Store 或其他第三方素材通常不能因被放進 GPL repo 就推定可再散布或改作。

建議決策門檻

  1. 現階段把 repo 當「可執行參考與 Unity 製作證據」，不要當已核准素材庫。
  2. 若要反轉 Unity 選型，先做小型、唯讀的 Unity 6.4 稽核：確認 LFS／子模組能完整還原、列出每個目標 mech 的 mesh／rig／animation／texture 依賴，並隔離第三方套件；仍不搬入正式專案。
  3. 真要重用前，需由權利人明確回答：哪些自製 FBX／貼圖／動畫／TerrainData 受 GPLv3 或另一資產授權、哪些來自 Asset Store／原作衍生、允許哪些商業與再散布方式。不必預設每個 GPL 自製素材都要另外取得許可；先釐清目標素材是否屬授權範圍與第三方例外，未釐清者選用來源較明確的替代素材。
