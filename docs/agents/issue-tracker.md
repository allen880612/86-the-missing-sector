# GitHub Issue 與 PR

使用 allen880612/86-the-missing-sector 的 GitHub Issues。需求先寫玩家價值與可觀察驗收，再拆成可完整試玩的增量。分支採 codex/ 前綴；PR 連結 Issue，包含改變的體驗、試玩證據、限制與 Review 結果。使用者已授權代理自行 Review 後 merge。需求與美術先行；不能把設計稿當作已實作玩法。

多行內容用 gh --body-file。Review 先看可玩性、回饋、可讀性、流程是否完整；保留必要的基本正確性與回歸檢查。無須因技能模板反覆要求已提供的權限。

PRs as a request surface: no.
