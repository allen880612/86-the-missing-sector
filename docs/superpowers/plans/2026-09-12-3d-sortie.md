# 立體戰場 S45–S47 Implementation Plan

> 使用 subagent-driven-development 分離模型、交戰核心、整合與獨立 QA。使用者已批准研究提案並授權自主 Sprint，不再重複設計確認。

**Goal:** 以真 3D 斜俯視、可操作多足機甲和地形，交付一段有整備、交戰、撤離及勝敗重試的工業廢墟戰鬥樣板。
**Architecture:** 新增獨立 sortie-3d.html 入口，Babylon.js 固定版本自託管；純 JS 可測核心與呈現分開。沿用既有音訊、機甲參考與字標。v45 2D 核心完全保留。
**Tech Stack:** Babylon.js 9.26.0 UMD、DOM/CSS、Node test、Chrome Playwright；Cloudflare Pages Free 純靜態。
**Spec:** art-direction/86-reference/3d-game-design.md 的 2026-09-12 提案。

## 目標與資源
- 週額度至少留 30%；65% 用量停止新派工、68% 停研究實作並收尾。
- S45：模型／步態／地形與相機達可辨識門檻；S46：整備→3職能協同交戰→撤離→結算；S47：獨立產品 QA、修正、PR/Pages 發布。時間是觀察值，不等固定30分鐘。
- Review 檢查玩家實際看到／能操作的結果；Retro 檢查協作返工原因。任何模型程序化製作明列為原型改編，不能宣稱官方模型或最終美術。
- 本地僅同步通過整合的完整新入口，既有 2D 不改平衡。不重啟8765服務。

## Task 1：Babylon 模型與環境（美術／技術美術 Astra）
Files: game-3d-models.js。只負責此檔，不改 core/UI。
Interface: window.SortieModels.create(scene) returns {createMech(kind,id), createEnvironment(obstacles), updateMech(rig,entity,time,dt), dispose()}. kind player/scout/hunter/heavy。rig {root,turret,muzzle,dispose()}。entity {x,z,angle,aimAngle,moving,speed,jumpHeight,recoil,hp,maxHp,phase}。世界 +y 上、前方 -z；yaw 0 面向 -z，方向 x=-sin(angle),z=-cos(angle)。root.position = (x,jumpHeight,z)。障礙 {id,x,z,w,d,h,type:'low'|'high',hp,maxHp}。
- [ ] 查官方 Babylon mesh/transform 文件與本地官方机型圖，記錄來源及模型限制。
- [ ] 製作可信四足玩家、六足斥候／獵兵、八足重戰車的差異輪廓；共享材質、低 mesh 負荷，砲口與獨立砲架。
- [ ] 動作必須步態循環、腳落地、砲管後座、躍進收腿／落地；停步不持續滑動。環境工業混凝土、低牆／高牆、鐵路與地標，低高牆可辨。
- [ ] 實機檢查不同機型大小、炮口朝向與動作，無需為純美術寫镜像測試。

## Task 2：地形與完整交戰核心（遊戲工程 Sol）
Files: game-3d-core.js, game-3d-core.test.cjs。CommonJS+window.SortieCore UMD。不改 v45。
Interface: create({seed}) -> state; start(state); step(state,input,dt); input {moveX,moveZ,aimX,aimZ,jump,skill,support}；state {phase:'ready'|'launching'|'playing'|'settling'|'won'|'lost',time,player,enemies,obstacles,projectiles,effects,events,objective,stats}。entity {id,kind,x,z,angle,aimAngle,moving,speed,jumpHeight,recoil,hp,maxHp,phase}; player extra {jumpCd,skillCd,supportCd}; events 每 step 清空 {type,x,z,...}; projectiles {id,x,z,dx,dz,enemy}; effects {id,type,x,z,life,maxLife,radius,...}。世界 x∈[-40,40],z∈[-48,48]；玩家起點0,34。
- [ ] 先紅測：高牆阻止彈／躍進，低牆可躍過但阻彈；斥候觀測使重砲追蹤最後位置、重砲發射前鎖定；獵兵有可躲預警；損血到零settling非瞬間結果。
- [ ] 實作自動主炮、RMB朝移動方向（無移動朝瞄準）有時間曲線躍進、LMB近身刃擊，Space範圍支援有冷卻。
- [ ] 斥候／獵兵／重型協作，有限增援，約3–5分鐘任務。含可破壞觀測節點及重型對手，解除威脅後走到撤離點而非計時自動贏；適當小量補給。不得改已接受的2D平衡。
- [ ] 結果資料固定、可重試、每步敵人／子彈／效果清除，保留界線外圈。
- [ ] meaningful deterministic tests 通過並提供 playability 調參紀錄（非真人勝率）。

## Task 3：整合呈現與流程（PO）
Files: sortie-3d.html, game-3d.css, game-3d.js, assets/vendor/babylon-9.26.0.js/LICENSE, index.html, scripts/build-pages.cjs/test, .github/workflows/pages.yml（以實際檔名為準）。
- [ ] 固定引擎自託管及 license，無 CDN 最新版及付費後端。
- [ ] 先背景scene，再克制的任務整備面板；玩家明確是白色多足機。滑鼠地面拾取、WASD、自動火力、RMB躍進、LMB刃擊、Space支援、P暫停。
- [ ] 運用既有音訊、場景BGM和字標。血量／技能compact底部，通訊可收起不擋中央；出击、失能淡暗與結算有過程，reduced-motion。
- [ ] 可辨識的預警與命中、火光、殘煙有數量和壽命限制。相機固定斜俯視，肩後比較留研發按鍵，不當主操作。
- [ ] 配合 build 測試發布新頁面/CSS/vendor；2D入口只加探索連結。
